# relicmink

Mink's bizarre adventure

Open `project.godot` in Godot 4.7 and run the project (F5) to enter the training room.

| Input | Action |
| --- | --- |
| A / D or Left / Right | Run and turn |
| Space | Jump, then press again in the air to double jump |
| Shift | Dash in the facing direction |
| H | Trigger hit and knockback on demand |

Use the raised platforms to test jumps and landings at different heights. Dash over the pit or fall in to return to the starting point. Touch the red spikes to test contact damage.

You can jump up to 100 ms after leaving a ledge. If a jump cannot start immediately, pressing Space up to 120 ms before landing queues a jump. When a double jump is available, Space uses it immediately.
